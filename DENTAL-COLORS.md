## Dental Practice Color Scheme

**Theme:** Professional Dental Clinic
**Colors:** Blue/teal based - clean, medical, trustworthy

### Color Palette

| Use | Color | Hex Code | Details |
|-----|-------|----------|--------|
| **Primary** | Deep Teal Blue | `#0891b2` | Main accent color - professional medical blue |
| **Secondary** | Cyan/Teal | `#0ea5e9` | Highlight/accent color |
| **Background** | Light Gray | `#f8fafc` | Clean, modern white-gray |
| **Dark Background** | Dark Teal | `#0f172a` | Hero/sections background |
| **Card Background** | White | `#ffffff` | Card backgrounds |
| **Text Primary** | Dark Slate | `#1e293b` | Main text |
| **Text Secondary** | Medium Slate | `#64748b` | Secondary text |
| **Border Accent** | Teal | `#0891b2` | Border highlights |

### Color Values

```tsx
// Primary Accent
const primary = "#0891b2"; // Deep teal blue
const secondary = "#0ea5e9"; // Cyan/teal

// Backgrounds
const bgLight = "#f8fafc"; // Light gray
const bgDark = "#0f172a";  // Dark teal
const bgCard = "#ffffff";  // White

// Text
const textPrimary = "#1e293b"; // Dark slate
const textSecondary = "#64748b"; // Medium slate

// Borders
const borderAccent = "#0891b2"; // Teal
```

### Gradient Accent (optional)
```tsx
// Gradient for buttons or highlights
const gradientAccent = "linear-gradient(135deg, #0891b2, #0ea5e9)";
```

### Notes
- Clean, medical, professional aesthetic
- Trustworthy blue/teal tones
- Not the ICT magenta scheme
- Appropriate for dental clinic branding
